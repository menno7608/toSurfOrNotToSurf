Privacy Policy — Archimedes OS

Last updated: 14 October 2026

Archimedes OS is a personal, single-user system operated by Menno Boot. It runs on a private Raspberry Pi at the operator's home and is used by one person: its owner. It is not a product, not a service offered to others, and it has no other users, customers or visitors.

This page describes exactly what the application does with data from Google accounts, because that is what its Google OAuth consent asks for.

What data is accessed, and what is kept

ScopeRead from GoogleStored on the device
gmail.readonly Message identifiers, the sender's address and the received date of mail from the last two days. Only the sender's domain (for example example.com), the date without a time, and the message id. Subjects and message bodies are never requested and never stored — the application asks Google for the Date header only.
calendar.readonly Events in a window around today. Event id, title, start time and last-modified stamp.
calendar.events Nothing beyond the event it creates. The id of each event it created, so the same event is never created twice.

Gmail access is read-only: no message is ever sent, deleted, modified or marked as read on the owner's behalf. The application holds no write permission on Gmail and contains no code that writes to it.

Calendar access is read-only with one exception: calendar.events lets the application add an event to the owner's own calendar, and only after the owner has explicitly approved that specific event in the application. It never changes or deletes existing events and never invites other people.

Where the data goes

  • Stored as plain files on a private Raspberry Pi at the operator's home, readable only by the operating-system account that runs the software.
  • Backed up to storage the operator controls: a NAS on the same home network and the operator's own cloud storage.
  • Never sold, never shared with third parties, never used for advertising, never used to train any model.
  • Not transferred to any server other than the operator's own. There is no hosted backend and no analytics.

Why the data is used

Solely to give the owner one overview of his own day: which messages arrived and which appointments are coming up. Nothing derived from this data leaves the owner's own devices.

Retention and deletion

Data is kept for as long as the owner keeps it and is deleted by deleting the files, which the owner can do at any time. Revoking access at myaccount.google.com/permissions immediately stops all further reading; the application then fails visibly rather than continuing silently.

Google API Services User Data Policy

Archimedes OS's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
